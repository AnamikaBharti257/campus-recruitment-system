# Campus Recruitment System

A MERN stack web application that simplifies the campus placement process by connecting students with companies.

### Features
- Student and company authentication
- Browse and post job opportunities
- Apply for jobs
- Resume upload
- Manage job applications

### Tech Stack
React.js, Node.js, Express.js, MongoDB, JavaScript, JWT
